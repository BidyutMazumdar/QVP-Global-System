2. Composite indices can introduce aggregation effects.
3. Rankings may be sensitive to weighting and normalization assumptions.
4. Missing or incomplete source coverage may affect comparability.
5. A higher index value does not establish causal superiority.
6. Rankings should be interpreted alongside uncertainty and sensitivity evidence.
