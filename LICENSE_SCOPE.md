# 1. PURPOSE

This document defines the licensing scope, rights boundaries, ownership boundaries, third-party rights controls, and commercial-rights reservations applicable to the **QSSI™ / QVP™ Global System V11**.

The purpose of this document is to prevent ambiguity regarding which materials may be used for public research and which rights remain separately reserved.

The QSSI™ / QVP™ Global System V11 therefore uses a **rights-separated, multi-layer licensing architecture** rather than assuming that every file, dataset, source code component, implementation, or repository artifact is governed by one universal license.

### Core Principle

> **Public research access does not constitute a transfer of commercial, proprietary, enterprise, SaaS, operational, production, governmental, or implementation rights.**

# 3. FUNDAMENTAL LICENSE BOUNDARY

The presence of a file, dataset, source code component, figure, algorithm description, report, archive, DOI, repository, or publication within the QSSI™ / QVP™ ecosystem does **not**, by itself, establish that the material is licensed under CC BY-NC-ND 4.0.

### The controlling rule is:

> **CC BY-NC-ND 4.0 applies only to materials expressly designated as being licensed under CC BY-NC-ND 4.0.**

Materials without such designation must not automatically be assumed to be covered by the public research license.

Where an artifact contains multiple rights classes, rights should be determined at the applicable component or artifact level wherever reasonably practicable.
